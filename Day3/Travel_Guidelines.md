# 여행 계획 검토 기준

> 실습용 검토 조건입니다. 아래 표의 값을 변경하여 사용할 수 있습니다.

| 항목 | 조건 |
|---|---|
| 여행 인원 | 성인 2명 |
| 여행 기간 | 3박 4일 |
| 여행 예산 | 총 2,000,000원 이내 (2인 합계) |
| 숙소 | 3성급 이상, 3박 |
| 하루 주요 관광지 | 최대 3곳 권장 |
| 자유시간 | 하루 최소 1시간 |
| 이동수단 | 대중교통 우선 |
| 여행 스타일 | 관광 60% / 맛집 40% |
| 예비비 | 총예산의 10% 이상 포함 |
| 필수 예산 항목 | 항공, 숙박, 식비, 현지 교통, 관광·체험, 예비비 |

## 검토 지시

- 위 조건을 기준으로 여행 일정과 예산을 검토한다.
- 조건을 충족하지 못한 항목과 개선안을 간단히 제시한다.
- 실제 가격이나 운영시간이 확인되지 않았다면 '확인 필요'로 표시한다.
- 사용자 요청과 이 문서의 조건이 충돌하면 충돌 사항을 명시한다.
